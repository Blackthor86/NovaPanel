# Contributing to NovaPanel

Thanks for taking an interest in NovaPanel.

## Before opening a pull request

- Keep changes focused and explain the user-facing reason.
- Add or update tests for behavior changes.
- Run `pytest` for backend changes.
- Run `npm run build` in `frontend/` for UI changes.
- Never commit credentials, subscription links, private keys, or real user data.
- Avoid logging tokens or configuration secrets.

## Project identity

Please keep copyright and license notices intact. Forks and modified builds should identify their changes and must not present themselves as the official NovaPanel project.
