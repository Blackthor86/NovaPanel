# استقرار NovaPanel روی هاست و دریافت خودکار اشتراک

## انتخاب خودکار یا مستقیم

NovaPanel دو حالت دارد. حالت **میزبان وب** برای هاستی است که فقط HTTP/HTTPS منتشر می‌کند، اما WebSocket Upgrade را تا برنامه عبور می‌دهد و اجازهٔ اجرای پردازش فرزند Xray را می‌دهد. حالت **سرور مستقیم** برای VPS یا سروری است که پورت ورودی عمومی واقعی دارد.

## حالت میزبان وب (PaaS)

1. فایل ZIP مخزن را روی یک هاست Linux که Python و Node.js دارد بارگذاری کن.
2. فرمان اجرا را روی `sh run-host.sh` قرار بده.
3. متغیر `NOVAPANEL_DEPLOYMENT_MODE=paas_ws` را تنظیم کن. در حالت `auto` نیز با دیدن `PORT` یا `SERVER_PORT` تلاش می‌شود این حالت انتخاب شود.
4. برای نشست‌ها مقدار قوی و ثابت `NOVAPANEL_SECRET_KEY` قرار بده و فضای ذخیره‌سازی پایدار را به `NOVAPANEL_DATA_DIR` متصل کن.
5. برنامه را باز کن و فقط رمز مدیر را تعیین کن. پنل از دامنهٔ عمومی درخواست یا متغیرهای میزبانی، آدرس را تشخیص می‌دهد و اتصال WebSocket را به‌طور خودکار می‌سازد.
6. کاربر را بساز؛ اگر موتور و پروفایل اتصال آماده باشند، پنل لینک اشتراک را خودکار نمایش می‌دهد. آن را در برنامهٔ VPN سازگار وارد کن.

در بار اول، اسکریپت راه‌انداز باینری رسمی Xray-core نسخهٔ pin‌شده را فقط برای Linux/amd64 یا Linux/arm64 دریافت و SHA-256 آن را بررسی می‌کند. اگر میزبان دانلود خروجی را مسدود کند، معماری پشتیبانی نشود یا اجرای پردازش فرزند را ممنوع کند، نصب خودکار کامل نمی‌شود.

## حالت سرور مستقیم

متغیر `NOVAPANEL_DEPLOYMENT_MODE=direct` را قرار بده. بعد در صفحهٔ «اتصال‌ها» اطلاعات واقعی دامنه/IP، پورت، مسیر و فایل گواهی/کلید خصوصی TLS را یک بار تعریف کن. سپس برای هر کاربر، لینک VLESS و لینک اشتراک از همان پروفایل ساخته می‌شود.

## محدودیت‌هایی که باید جدی گرفت

- دامنهٔ HTTPS به‌تنهایی تضمین نمی‌کند که میزبان WebSocket Upgrade را عبور می‌دهد.
- میزبان باید اجرای Xray به‌عنوان child process، دانلود باینری رسمی در اولین شروع، مصرف منابع کافی و تداوم SQLite را مجاز کند.
- با خاموش‌شدن، sleep، restart یا filesystem موقت، سرویس ممکن است از دسترس خارج شود یا اطلاعات محلی از بین برود؛ ذخیره‌سازی پایدار الزامی است.
- وضعیت «پروفایل خودکار» صرفاً ایجاد پیکربندی را نشان می‌دهد، نه اثبات اتصال بیرونی. لینک اشتراک را با یک کلاینت واقعی آزمایش کن.
- اگر ارائه‌دهنده استفاده از proxy/VPN را ممنوع کرده، دورزدن آن محدودیت جزو NovaPanel نیست؛ از میزبان مجاز استفاده کن.
