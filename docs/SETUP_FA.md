# راه‌اندازی NovaPanel روی هاست Node.js

NovaPanel برای استقرار جدید فقط به Runtimeِ **Node.js 20 یا 22** نیاز دارد. رابط کاربری و API در یک برنامه اجرا می‌شوند؛ Python لازم نیست.

## روش پیشنهادی: بستهٔ آمادهٔ استقرار

1. اجرای موفق workflow با نام **CI** را در [GitHub Actions مخزن NovaPanel](https://github.com/Blackthor86/NovaPanel/actions) باز کن.
2. فایل Artifact به نام \`NovaPanel-node-deploy\` را دانلود کن. آرشیو Artifact ممکن است خودش یک فایل ZIP دیگر به نام \`NovaPanel-node-deploy.zip\` درونش داشته باشد؛ **فایل داخلی را استخراج و در هاست آپلود کن، نه ZIP بیرونی Artifact**.
3. تأیید کن که \`package.json\` مستقیماً در ریشهٔ ZIP آپلودشده قرار دارد؛ ZIP نباید فقط یک پوشهٔ اضافی یا ZIP تو‌در‌تو در ریشه داشته باشد.
4. Runtime را روی Node.js 22 قرار بده و دستور شروع را \`npm start\` تنظیم کن.
5. متغیر \`NOVAPANEL_SECRET_KEY\` را روی یک مقدار تصادفی و طولانی تنظیم کن و برای \`NOVAPANEL_DATA_DIR\` فضای ذخیره‌سازی پایدار در نظر بگیر.
6. پس از راه‌اندازی، دامنهٔ HTTPS را باز کن و در اولین اجرا رمز مدیر با حداقل ۱۴ کاراکتر بساز.

بستهٔ آمادهٔ CI فایل‌های کامپایل‌شده را هم دارد، بنابراین برای شروع نیاز نیست هاست در همان لحظهٔ راه‌اندازی فرانت‌اند و سرور را کامپایل کند. اگر ZIP سورس خام را آپلود کنی، \`npm start\` در اولین اجرا ساخت برنامه را انجام می‌دهد و موقتاً CPU بیشتری مصرف خواهد کرد.

## تنظیم پورت و دامنه در Botkeep

- دستور شروع را \`npm start\` قرار بده.
- NovaPanel در صورت وجود \`SERVER_PORT\` ابتدا روی همان پورت گوش می‌کند؛ فقط اگر متغیر وجود نداشته باشد از \`PORT\` استفاده می‌کند.
- در Botkeep، برای دسترسی HTTP باید دامنه را از بخش **Domains** تنظیم/فعال کنی. اطلاعات تب **Network** به‌تنهایی تضمین نمی‌کند که URL وب از طریق HTTPS به برنامه هدایت شده باشد.
- برای اینکه نصب Xray هم در شروع پنل اجرا نشود، NovaPanel اکنون موتور را تا زمان نیاز واقعی به‌صورت تنبل نصب می‌کند. ساخت اولین کاربر می‌تواند نصب موتور را در پس‌زمینه آغاز کند؛ خود پنل باید در این مدت در دسترس بماند.

## متغیرهای محیطی پیشنهادی

| متغیر | مقدار |
|---|---|
| \`NOVAPANEL_SECRET_KEY\` | مقدار تصادفی و طولانی و ثابت |
| \`NOVAPANEL_DATA_DIR\` | مسیر volume پایدار برای دیتابیس و لاگ‌ها |
| \`NOVAPANEL_DEPLOYMENT_MODE\` | \`paas_ws\` |
| \`NOVAPANEL_COOKIE_SECURE\` | \`1\` وقتی HTTPS فعال است |
| \`NOVAPANEL_AUTO_INSTALL_XRAY\` | مقدار پیش‌فرض \`1\`؛ برای غیرفعال کردن دانلود خودکار \`0\` |

## تست اولیه

بعد از بالا آمدن دامنه، مطمئن شو این مسیر پاسخ می‌دهد:

\`https://دامنه-تو/api/health\`

باید پاسخ JSON شامل \`"status":"ok"\` بدهد. سپس صفحهٔ اصلی پنل را باز کن و رمز مدیر را تنظیم کن. اگر مسیر سلامت هم باز نمی‌شود، قبل از بررسی VPN، Console هاست را بررسی کن و ببین در لاگ نوشته شده برنامه روی چه پورتی گوش می‌دهد.

لینک اشتراک ساخته‌شده به‌تنهایی اتصال واقعی را ثابت نمی‌کند. قبل از توزیع، پروفایل را با کلاینت واقعی آزمایش کن. هاست باید WebSocket Upgrade و اجرای پردازش Xray را پشتیبانی کند.
