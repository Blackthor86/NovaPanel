# راه‌اندازی NovaPanel

NovaPanel برای استقرار جدید از یک Runtime یعنی **Node.js** استفاده می‌کند. رابط React/TypeScript و API مدیریتی هر دو در همان برنامه اجرا می‌شوند؛ برای اجرای سرور نیازی به Python نیست.

## روش پیشنهادی: ZIP آمادهٔ استقرار

1. از GitHub، آخرین اجرای موفق workflow با نام **CI** را در شاخهٔ `main` باز کن.
2. در بخش Artifacts، فایل `NovaPanel-node-deploy` را دریافت و ZIP داخل آن را استخراج یا مستقیماً در هاست بارگذاری کن.
3. نوع Runtime را Node.js 20 یا 22 انتخاب کن.
4. دستور شروع را `npm start` قرار بده.
5. متغیر `NOVAPANEL_SECRET_KEY` را روی یک مقدار تصادفی و طولانی تنظیم کن و برای `NOVAPANEL_DATA_DIR` فضای ذخیره‌سازی پایدار در نظر بگیر.
6. اگر هاست متغیر `PORT` یا `SERVER_PORT` ارائه کند، NovaPanel به‌طور پیش‌فرض حالت میزبان وب را تشخیص می‌دهد. در صورت نیاز می‌توانی `NOVAPANEL_DEPLOYMENT_MODE=paas_ws` را صریح تنظیم کنی.
7. دامنهٔ HTTPS برنامه را باز کن و در اولین اجرا رمز مدیر با حداقل ۱۴ کاراکتر بساز.

ساختار ZIP از قبل سورس لازم را دارد؛ دستور `npm start` فرانت‌اند و سرور TypeScript را می‌سازد و سپس برنامه را اجرا می‌کند. برای این کار سرویس Python جداگانه‌ای تنظیم نمی‌شود.

## اجرای محلی

Node.js 20 یا جدیدتر نصب کن. سپس در ریشهٔ پروژه اجرا کن:

```sh
npm install
npm start
```

برنامه معمولاً روی `http://127.0.0.1:8000` در دسترس قرار می‌گیرد. برای ساخت بدون اجرا:

```sh
npm run build
```

برای اجرای تست‌های API:

```sh
npm test
```

## انتخاب حالت اتصال

- **حالت میزبان وب** (`paas_ws`): پنل یک مسیر WebSocket و لینک اشتراک HTTPS می‌سازد. میزبان باید ارتقای WebSocket را عبور دهد و اجرای پردازش Xray را مجاز بداند.
- **حالت مستقیم** (`direct`): برای سرور دارای پورت ورودی عمومی؛ Xray و گواهی TLS را نصب کن و یک اتصال را یک‌بار از پنل تنظیم کن.

در حالت میزبان وب، NovaPanel برای Linux سازگار، در صورت نبود باینری Xray، نسخهٔ رسمی پین‌شده را دریافت و SHA-256 آن را پیش از نصب بررسی می‌کند. اگر دانلود یا اجرای موتور ممکن نباشد، خود داشبورد همچنان بالا می‌آید اما ساخت لینک به معنی اتصال موفق نیست.

## امنیت

- پیش از استقرار عمومی [SECURITY.md](../SECURITY.md) را بخوان.
- یک `NOVAPANEL_SECRET_KEY` ثابت و تصادفی تعیین کن.
- پس از فعال‌شدن HTTPS مقدار `NOVAPANEL_COOKIE_SECURE=1` را تنظیم کن.
- پوشهٔ داده باید پایدار و دارای دسترسی محدود باشد؛ در غیر این صورت ممکن است دیتابیس با حذف یا بازسازی سرویس از بین برود.
- قبل از توزیع لینک اشتراک، آن را با یک کلاینت واقعی آزمایش کن.
- وجود دامنهٔ HTTPS یا ساخته‌شدن لینک، پشتیبانی شبکه و قابلیت دسترسی سرویس را اثبات نمی‌کند.
