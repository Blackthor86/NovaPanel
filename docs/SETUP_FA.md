# راه‌اندازی NovaPanel ساده‌شده روی هاست

این نسخه برای نزدیک‌شدن به جریان سادهٔ Blue Knight ساخته شده: یک برنامهٔ Node.js، یک پورت عمومی، ساخت رمز مدیر در اولین ورود، و یک لینک اشتراک برای دریافت خودکار همهٔ پروفایل‌ها در V2Ray.

## استقرار پیشنهادی

1. اجرای موفق CI را در GitHub Actions مخزن باز کن و Artifact به نام NovaPanel-node-deploy را دانلود کن. (برای شاخهٔ آزمایشی Pull Request، نام Artifact برابر NovaPanel-blue-knight-lite-preview است.)
2. ZIP دانلودشدهٔ Artifact یک ZIP بیرونی است که فایل NovaPanel-blue-knight-lite.zip را داخل خود دارد. ابتدا ZIP بیرونی را استخراج کن، سپس ZIP داخلی را هم استخراج کن و محتویات آن را در File Manager هاست قرار بده.
3. بررسی کن که package.json مستقیماً در ریشهٔ فایل‌های برنامه باشد؛ پوشهٔ اضافه یا ZIP تو‌در‌تو نباید باقی مانده باشد.
3. مطمئن شو فایل package.json مستقیماً در ریشهٔ پوشهٔ برنامه است.
4. Runtime را روی Node.js 22 بگذار و فرمان شروع را npm start قرار بده (معادل node index.js).
5. متغیر SERVER_PORT را همان مقداری بگذار که هاست برای اتصال عمومی اختصاص داده است؛ اگر هاست آن را خودش تزریق می‌کند، آن را تغییر نده. برنامه در صورت وجود SERVER_PORT، همان را به PORT ترجیح می‌دهد.
6. پوشهٔ دادهٔ پایدار انتخاب کن؛ مقدار پیشنهادی NOVAPANEL_DATA_DIR=./bk-data است، به شرطی که آن مسیر واقعاً روی volume پایدار و قابل‌نوشتن باشد.
7. برنامه را بالا بیاور و URL وب را که Botkeep در اختیار می‌گذارد باز کن. ورود نخستین بار باید صفحهٔ ساخت رمز مدیر را نشان بدهد؛ نام کاربری لازم نیست.
8. بعد از ورود، لینک اشتراک را کپی کن. در V2Ray از بخش Subscription آن را اضافه کن، سپس Update/Refresh Subscription را بزن. لینک تکی را به‌جای لینک اشتراک وارد نکن.

## بررسی قبل از تست کلاینت

مسیر /api/health باید JSON برگرداند و پورت اختصاصی هاست را گزارش کند. صفحهٔ پنل باید حتی زمانی که Xray در حال دانلود و نصب است در دسترس بماند. وقتی نصب موتور تمام شد، engine_status باید running باشد.

این نسخه یک TCP listener واقعی روی پورت عمومی دارد؛ درخواست‌های HTTP به پنل می‌روند و ترافیک TLS به TLS داخلی هدایت می‌شود. مسیرهای WebSocket هم به Xray محلی متصل می‌شوند. بنابراین برای direct mode نباید لینک را به دامنه/پورت اشتباه هدایت کرد. اگر هاست فقط HTTP را از طریق reverse proxy پاس می‌دهد و TLS خام را روی پورت اختصاصی به برنامه نمی‌دهد، direct mode برای آن مسیر مناسب نیست؛ فقط در هاست‌هایی که edge با WebSocket Upgrade کار می‌کند از NOVAPANEL_LINK_MODE=edge استفاده کن.

## ماندگاری

پوشهٔ bk-data حاوی UUID، توکن اشتراک، مسیرهای WebSocket، هش رمز و گواهی TLS است. پاک‌کردن یا reset شدن این پوشه باعث تغییر لینک‌ها می‌شود و باید اشتراک را دوباره به V2Ray وارد کنی.

## وضعیت قابلیت‌ها

این نسخهٔ پایه فقط VLESS-WS، VMess-WS و Trojan-WS را با و بدون TLS تولید می‌کند. هنوز پنل چندکاربرهٔ نسخهٔ قبلی، سهمیهٔ ترافیک، Clash، خروجی sing-box، Reality، gRPC و XHTTP در این runtime ساده پیاده نشده‌اند. ابتدا اتصال واقعی و به‌روزرسانی ساب را روی هاست هدف تست کن؛ سپس قابلیت‌ها را مرحله‌به‌مرحله اضافه می‌کنیم.
